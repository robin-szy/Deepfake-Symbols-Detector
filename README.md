# deepfake-symbols-detector

A deep learning classifier that detects whether a handwritten symbol was drawn by a human or generated by AI, based on raw pen stroke data.

## Problem

Given time-series pen stroke recordings (x/y coordinates, timestamps, stroke IDs), classify each symbol as **real** (human-drawn) or **fake** (AI-generated).


## Model

A hybrid GRU-based classifier that processes variable-length writing sequences:

- A 1-layer GRU processes the sequential stroke features
- Six handcrafted global features describing the complete symbol are projected into a 3-dimensional bottleneck
- The GRU representation and global features are concatenated and passed through a fully connected classification head with layer normalization, ReLU activation, and dropout
- A final logit is converted to a fake-symbol probability using a sigmoid activation

Input features per timestep (11 total): `dx, dy, log displacement (r), sin(direction), cos(direction), change in direction, dt, stroke change, log curvature, log speed, log acceleration`

Global features (6 total): presence of large time gaps, sequence length, total duration, mean and standard deviation of displacement, and directional variability.

## Dataset

3,670 symbol samples (1,835 real, 1,835 fake) stored as tab-separated `.csv` files under `symbols/real/` and `symbols/fake/`. Each file contains columns: `stroke_id, x, y, time, is_writing`.

The dataset is not included in this repository as it was provided by the course instructor.

## Usage

**Install dependencies:**
```bash
pip install -r requirements.txt
```

**Train:**
```bash
python train.py
```
Runs 5 independent training runs with early stopping and saves the best model to `model.pth`.

**Predict:**
```python
from eval import load_and_predict

results = load_and_predict("path/to/symbols/dir", "model.pth")
# returns {filename: 0 (real) or 1 (fake), ...}
```
